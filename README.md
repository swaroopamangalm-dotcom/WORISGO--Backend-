# WORISGO Internship — Backend & Full-Stack Projects

Public portfolio repository for **backend and full-stack web application work completed during my internship at WORISGO**.

The uploaded internship reports document three database/API-driven applications. They are separated below according to their system role.

## Projects

### 1. Laravel Task Manager
**Category:** Full-stack / Backend-focused

**Technologies documented:** Laravel, PHP, Bootstrap, REST API, AJAX, Laravel Passport, MySQL, Postman, Mailtrap.

**Documented functionality**
- Create, view, update, and delete tasks
- RESTful API communication using GET/POST/PUT/DELETE
- Token-based authentication with Laravel Passport
- AJAX-based asynchronous interaction
- MySQL data management
- API testing using Postman
- Email testing with Mailtrap

### 2. Simple Blogging Platform
**Category:** Full-stack

**Technologies documented:** HTML, CSS, JavaScript, Bootstrap 4, PHP, MySQL.

**Documented functionality**
- Create blog posts
- Read/display posts
- Edit posts
- Delete posts
- Timestamps
- Client/server validation
- Database-backed content management

The project follows a client-server architecture with PHP handling server-side operations and MySQL storing blog data.

### 3. Booking Management System for Room Booking
**Category:** Full-stack

**Technologies documented:** PHP, Laravel, MySQL, Eloquent ORM, HTML, CSS, Bootstrap.

**Documented functionality**
- Submit room booking requests
- Store booking details
- Track booking status
- Administrative booking management
- Approve/reject booking requests
- Manage room availability
- Validation and data sanitization
- Responsive frontend
